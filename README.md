# Adaptive AI Solutions

> **English TL;DR:** Independent AI developer portfolio — voice-first products, multi-agent orchestration, self-hosted platforms and formal verification. Everything below ships as working code with tests, not slideware.

Ich baue KI-Produkte und die Infrastruktur dahinter — vom Voice-first-Invoicing bis zur Multi-Agent-Orchestrierung. Schwerpunkte: **AI-Integration** (Gemini, Agenten-CLIs), **Fullstack-TypeScript** (Next.js, Electron), **Python und IoT** sowie **formale Verifikation**. Nach dem Motto: lokale First, DSGVO by Design, Hosting in Frankfurt.
